#### Розглянуті теми:

1. **Рядкові дані (`str`)**
   - Рядки як об'єкти Python: методи `.count()`, `.split()`, `.upper()`, `.strip()`
   - Зрізи (slices): `s[0]`, `s[-1]`, `s[2:5]`
   - Конкатенація та множення рядків
   - f-strings та форматування виводу

2. **Числові типи (`int`, `float`, `complex`)**
   - Цілочисельне ділення `//` та остача від ділення `%`
   - Оператор піднесення до степеня `**`
   - Логічні операції з числами
   - Порівняння `==` vs `is`

3. **Списки (`list`)**
   - Створення, індексація, зрізи
   - Методи: `.append()`, `.pop()`, `.sort()`, `.reverse()`
   - Вкладені списки та list comprehension

4. **Кортежі (`tuple`) та множини (`set`)**
   - Незмінність кортежів
   - Операції з множинами: об'єднання, перетин, різниця

5. **Словники (`dict`)**
   - Створення та доступ до елементів
   - Методи: `.keys()`, `.values()`, `.items()`
   - dict comprehension

6. **Умовні конструкції та цикли**
   - `if / elif / else`
   - Цикли `for` та `while`
   - Оператори `break`, `continue`, `pass`
   - Вбудована функція `range()`

7. **Функції**
   - Оголошення через `def`
   - Аргументи за замовчуванням, `*args`, `**kwargs`
   - Lambda-функції
   - Рекурсія

8. **Обробка помилок**
   - `try / except / finally`
   - Типові виключення: `TypeError`, `ValueError`, `IndexError`

#### Приклад власного коду:
```python
# Перевірка паліндрому з використанням рядкових методів
def is_palindrome(text: str) -> bool:
    cleaned = text.lower().replace(" ", "")
    return cleaned == cleaned[::-1]

words = ["level", "Python", "racecar", "hello"]
for word in words:
    result = "паліндром" if is_palindrome(word) else "не паліндром"
    print(f"'{word}' — {result}")
```
